# 慢慢唸 · 台語朗讀練習

前三篇為：陳雅菁〈阿媽的查某囝〉（8 段，附錄音與台羅）及巫素宜〈阮兜的糖霜丸〉（5 段，附三份錄音、逐詞台羅、螢光筆與練習記號，22 句為待聽校初切版本），以及蔡靜慧〈苦瓜哪會苦〉（附五份錄音與逐詞台羅）。練習頁上方可切換篇目，第二篇網址為 `/?article=02`。第一篇原始初切 23 句，可自行分割增加短句。使用 Node.js 22 以上；前端不需要安裝套件。

## 本機啟動

雙擊 `start.cmd`，或在此資料夾執行：

```powershell
node server.mjs
```

- 練習：http://localhost:4173/
- 本機校對與重錄：http://localhost:4173/editor
- 第二篇練習：http://localhost:4173/?article=02
- 第二篇校對：http://localhost:4173/editor?article=02
- 第三篇練習：http://localhost:4173/?article=03
- 第三篇校對：http://localhost:4173/editor?article=03

服務只監聽本機 `127.0.0.1`。線上版本只有練習頁；沒有校對頁、錄音入口或本機寫入 API。

## 練習與螢光筆

可整篇、整段、逐句聆聽，支援單句循環、速度、字級、音量、跟隨朗讀及練習記號。整段與整篇會依校對結果使用採用的單句重錄版本。

選取同一句中的字詞，再按「標記選取文字」。可選暖黃、薄荷綠、粉紅；選取後按「清除選取標記」可局部擦除。開啟「螢光筆」後，也能點字標記或取消，方便手機使用。標記、練習進度與台羅顯示設定儲存在此瀏覽器，不會跨裝置同步。

「顯示台羅」可切換逐詞拼音。來源是使用者提供的對照稿，沒有使用自動翻譯。已依使用者修正「𤆬＝tshuā」，並刪除多出的「抨、去」，稿文為「伊的煩惱就攏擲挕捒矣」。目前全部漢字都有對照。`sources/tailo-pasted.txt` 保留對照來源，`scripts/prepare_tailo.py` 產生 `public/tailo.json`。

空白鍵播放／暫停，方向鍵切換句子；在輸入欄位中不會觸發。

## 本機校對與重錄

點句子或旁邊的「編輯／分割／重錄」，工具直接展開在該句下方，不必回到頁首。切換分頁即可就地操作，關閉後仍停留在該句。「微調原錄音句界」內的波形可定位原音；設定起訖秒數，或以播放位置設定。共用句界會一起調整，受影響的相鄰句回到待確認。

可修改稿文、台羅整句修訂及備註。台羅修訂欄留空時使用逐詞對照；若修改漢字，需同步填寫新台羅整句，否則不顯示不相符的舊對照。按「儲存本句修改」直接寫入專案，試聽後按「確認完成並儲存」。待確認／已確認是聽校進度，不是批次選取，也不影響播放；改稿、改時間、重錄或分割後會自動回到待確認。校對頁不顯示練習用的圓形勾選。

分割長句：在「文字分割位置」中點選游標，查看前後文字預覽；播放該句，在切點暫停，按「使用目前播放位置」，也可直接輸入分割秒數。試聽前句、後句後，按「確認分割並儲存」。按下後會一次儲存兩句並標記已確認；成功即收起工具、回到句子列表，不需再按儲存或確認。若寫入失敗則保留原句與分割設定，不會再分割一次。預設秒數只是參考，並非語音強制對齊。分割保留原稿順序與逐詞台羅；若從單一台羅詞內切開，該詞的兩半不猜拼音，可自行補寫整句台羅。有整句台羅修訂時須分別填寫兩句拼音。

已採用的重錄會以同一音檔的前後區間保留，兩句可各自重新錄製，恢復原音仍可使用原始錄音對照。「復原最近一次分割」只在此頁面工作階段且尚未進行其他修改時可用；重新載入後分割結果會保留，但不保留復原按鈕的歷史。

單句重錄流程：

1. 選取要重錄的句子，按「開始錄音」，允許瀏覽器麥克風權限。
2. 按「停止錄音」，試聽候選音檔；不滿意可捨棄再錄。
3. 按「採用這次重錄」，於本機先以雙遍響度處理平衡至 −18 LUFS、限制 true peak −1.5 dBTP，再轉為 AAC，儲存至專案。
4. 新版本會用於單句、整段及整篇播放。「試聽原句」仍可比對原音；「恢復原音」可取消採用。

錄音上限 180 秒、20 MB；不支援麥克風錄音的瀏覽器可匯入 WAV、M4A、WebM、OGG 或 MP3。錄製中或候選尚未採用時，會擋下切換句子以防誤套。麥克風只在按下錄音後啟動，停止即釋放。

`Voice/` 原檔不覆寫。採用音檔與原始重錄放在 `.local/recordings/`，不會自動傳到雲端；同資料夾的 `.processing.json` 留存每次重錄的測量與處理參數。重新建立並部署練習頁時，僅複製當前採用的處理版音檔；候選、已撤銷與原始重錄不會加入部署包。

## 儲存與部署

校對修改先暫存於此瀏覽器。「儲存本句修改」、確認或分割時，寫入 `.local/article.json`，前一份為 `.local/article.json.backup`。本機練習頁重新整理後使用已儲存版本。校對 JSON 可匯入／匯出並保留分句；JSON 中的錄音路徑不包含錄音檔本身，跨電腦轉移時須一併保留 `.local/recordings/`。

建立只含練習頁的靜態部署包：

```powershell
node scripts/build-practice.mjs
```

輸出 `sites/slow-reading/dist/`，僅含練習頁程式、台羅資料、已儲存稿文、音量調整錄音與當前採用的重錄。校對 HTML／JS、伺服器、寫入 API、備註、原始 Voice 錄音、來源稿與未採用的錄音都不加入。Sites 設定於 `sites/slow-reading/.openai/hosting.json`；本機修改不會自動更新線上版，須重建、重新部署。

## 音訊處理與檢查

四份原音對應第 1–2、3–4、5、6–8 段，總長約 3 分 24 秒。原音約 −26 至 −28 LUFS，`public/audio/` 使用雙遍響度正規化，實測約 −17.95 至 −18.16 LUFS。`audio-report.json` 與 `audio-verification.json` 記錄測量。

本機重錄處理需要 FFmpeg。可設定 `FFMPEG_PATH` 指向 FFmpeg 執行檔，或安裝：

```powershell
python -m pip install imageio-ffmpeg --target .tools/python
```

重建原始錄音衍生檔的 `scripts/prepare_audio.py` 需要 imageio-ffmpeg。重跑會覆寫初切資料，請先備份。原始 23 句句界依停頓估計，尚需逐句聽校；支援分割長句，目前校對頁不支援合句或新增篇目。

驗證：

```powershell
node scripts/build-practice.mjs
node --test tests/*.test.mjs
```

涵蓋全文與台羅對應、句界檢查、重錄播放計畫、音訊上傳轉檔與儲存、音訊定位，以及部署內容隔離。瀏覽器測試使用本機產生的測試音檔，不代表已驗證使用者麥克風的實際收音品質。

第二篇台羅來源保存在 `sources/tailo-02-pasted.txt`，執行 `python scripts/prepare_tailo.py --second` 可重建 `public/tailo-02.json`。22 句的漢字皆有使用者提供的對照。

第二篇音訊使用 `python scripts/prepare_audio.py --second` 建立，需 imageio-ffmpeg。三份原音暫按第 1–2、3、4–5 段對應，總長約 4 分 27 秒；句界依停頓估計，尚未逐句人工聽校。原檔保留於 `Voice/`，音量調整版在 `public/audio/tang-sng-uan/`，實測約 −18.02、−18.01、−18.18 LUFS。處理與測量記錄分別為 `audio-report-02.json`、`audio-verification-02.json`。重跑音訊準備會覆寫第二篇初切資料，請先備份。

第二篇校對獨立儲存於 `.local/article-02.json`，備份為同名 `.backup`，不會覆寫第一篇；重錄沿用 `.local/recordings/`，由篇目與句子識別選擇套用對象。建立部署包時會同時封裝三篇已儲存稿文與採用音檔，移除來源錄音路徑、波形和校對備註。

第二篇加入標題與作者後，可執行 `python -X utf8 scripts/realign-second.py` 預覽按短語停頓重新對齊的結果；加上 `--apply` 才寫入，會先備份原始初切稿與已儲存稿，保留分句識別、文字、台羅修訂及採用重錄，將句界設為待確認。另需 NumPy。結果記錄於 `audio-realignment-02.json`，仍屬停頓估計而非語音辨識或人工聽校。

第三篇〈苦瓜哪會苦〉使用 `sources/tailo-03-pasted.txt` 的校對稿。先執行 `python -X utf8 scripts/prepare_audio.py --third` 產生初切資料與五份音量調整檔，再執行 `python -X utf8 scripts/prepare_tailo.py --third` 產生逐詞台羅。依錄音順序將五份原音對應到篇名與首段、第二段、第三段、第四段、末兩段；句界依停頓估計，待逐句聽校。處理紀錄在 `audio-report-03.json`，校對另存於 `.local/article-03.json`。

重新對齊會更新句界版本。重新載入校對頁後不會套用舊版本草稿；舊草稿保留於瀏覽器的備份鍵。舊頁面的儲存要求會被拒絕，請先重新整理，避免把舊切點覆寫回專案。修改資料後需重啟已在執行的本機服務，再重建部署包。
